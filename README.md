# snapquiz

个人学习刷题助手 —— 热键一按,读取屏幕上的题目,调用 LLM 给出**答案 + 解析 + 相关知识点**,辅助自学、自测与错题复习。

> 状态:🚧 早期阶段(可行性评估已完成,进入 MVP 开发)。

## 这是什么

一个运行在 macOS 上的**个人学习工具**:

```
热键触发 → 截取屏幕题目区域 → OCR 或多模态 LLM 识别 → 生成「答案 + 解析」→ 本机呈现(可选推送到手机)
```

目标是帮助**自学与复习**,而不是替你思考——支持「先自己作答、再看 AI 解析」的模式,并沉淀错题本。

## 定位与边界

- ✅ **适用**:个人自学 / 自测练习 / 无障碍辅助 / 休闲趣味竞答
- ⛔ **不适用**:受监考的考试、认证考试、技术面试等任何被监控的评估场景。这属于学术不端,**本项目不实现任何"规避监考 / 隐藏窗口 / 反检测"相关功能**。

## 规划架构

| 阶段 | 方案 |
|---|---|
| **捕获** | 原型 `screencapture -x -R`;成品 ScreenCaptureKit。触发用全局热键(`RegisterEventHotKey`,仅需屏幕录制权限) |
| **识文** | 纯文字题走 Apple Vision 端上 OCR(免费、数据不出本机);数学公式/图表题直接把截图喂多模态 LLM |
| **作答** | LLM 强制结构化输出 `{answer, rationale}`。默认 Claude Sonnet 5;难题升 Opus + 推理;省钱用 Gemini Flash / Haiku |
| **呈现** | 本机弹窗/菜单栏;可选 ntfy.sh 推送到手机 |

## 现实预期

- 纯文字选择题准确率 ~85–95%+;**图表/几何/看图题会明显下降**。
- 端到端延迟:不开推理 ~1.5–6 s,开推理 6–30 s+。
- 单题成本:不到一分钱到几分钱。
- 内置**幻觉护栏**:低置信弃答/标注不确定,答案附解析供人工核对。

## 路线图(MVP)

- **MVP-0** —— 半天:`screencapture` 抓固定区 → 喂视觉 LLM(严格 schema)→ 本机弹窗。验证准确率与延迟。
- **MVP-1** —— 几天:热键触发 + 端上 Vision OCR + 健壮性(权限自检、退避重试、fail-closed)+ 幻觉护栏 + 错题本。
- **MVP-2** —— 可选:Swift + ScreenCaptureKit 重写为签名公证的菜单栏 App + launchd 自启。
